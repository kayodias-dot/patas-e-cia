# Referências visuais e ativos

## Referência indicada

Heritage Animal Hospital: https://heritage-vets.com/.

Foi utilizada como referência para uma página acolhedora, com apresentação, missão, diferenciais, chamadas de ação e acesso ao sistema. A versão entregue é uma adaptação da proposta visual à marca fictícia Patas & Cia. O sistema de cadastros e sua API foram implementados separadamente, não copiados de um sistema da clínica real.

A comparação visual completa, pixel a pixel, com o site real não foi realizada. A consulta externa retornou a estrutura textual e parte das imagens de referência. O resultado deve ser entendido como primeira adaptação, sujeita à revisão visual da equipe.
